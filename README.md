# Listen45

Recognize music. Not users.

Privacy-first, ad-free, lightweight Android music recognition.

Listen45 is planned as a GPL-3.0 derivative of [Audire](https://github.com/alexmercerind/audire). The original source and copyright notices will be retained when imported.

Brand accent: `#60A5FA` (Media45).

No ads, analytics, accounts or tracking. Prefer local processing and open recognition providers. Shazam is not a permanent dependency goal.
